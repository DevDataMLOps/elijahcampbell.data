# Elijah Campbell — Portfolio

Static Cloud and Data Engineering portfolio ready for GitHub Pages.

## Publish with GitHub Pages
1. Extract this ZIP.
2. Upload the **contents inside `portfolio_work`** to the root of your GitHub Pages repository.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, `main`, and `/(root)`.
5. Save.

## Included features
- Responsive one-page engineering portfolio
- Dark/light theme with saved preference
- Live GitHub repository cards with offline fallback
- Project RISING case study
- Animated data-platform architecture
- Experience timeline and measured outcomes
- Accessible navigation and reduced-motion support
- Search-engine and social-sharing metadata
- Downloadable CV
